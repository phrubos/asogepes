# 2026 előtti javítások — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** P0–P1 javítások (gyors, mobilon olvasható, akadálymentes oldal) a 2026-os adatfeltöltés előtt.

**Architecture:** Nincs új architektúra: meglévő komponensek és CSS-modulok javítása. A „tesztek” a `scripts/qa/` Playwright-szkriptek; mindegyik nem-nulla kóddal lép ki, ha az elfogadási feltétel sérül. Így minden feladat piros → zöld ciklusban halad.

**Tech Stack:** Next.js 15.5 (App Router), React 18, Framer Motion 11, CSS Modules, Playwright 1.57 (Chromium).

**Spec:** `docs/superpowers/specs/2026-10-31-pre-2026-hardening-design.md`

## Global Constraints
- Minden mérés production buildön: `npm run build && npx next start -p 3000` (a régi szervert előtte le kell állítani; Windows-on a port PID-jét `netstat -ano` + `taskkill //PID <pid> //F //T`).
- Nincs új futásidejű függőség. A `next` és az `eslint-config-next` pontosan `15.5.28`.
- Földszín-paletta, kék/indigó tilos; a meglévő `--color-*` tokenek használandók.
- Minden animáció tiszteli a `prefers-reduced-motion`-t.
- Minden feladat végén: `npx tsc --noEmit`, `npm run lint` (0 hiba), és az adott feladat QA-szkriptje zöld.
- A naplóba (`docs/superpowers/progress/2026-10-31-pre-2026-hardening.md`) feladatonként egy sor: mi készült, döntések („Ruling: … — cost if wrong: …”), mérés.

## Review Focus
1. **Lassú videó asztalon**: a poster látszik, a szöveg nem vár a videóra → `hero-check.js` asztali lassított futás is (Task 3).
2. **125%-os Windows-skálázás (1536×864)**: a nagyobb betű nem vág le tartalmat → `clip-check.js` 1536×864 (Task 5).
3. **Hover + koppintás ugyanazon az eszközön** (érintős laptop): a kártya koppintásra nem nyílik-zárul azonnal (hover+click dupla toggle) → touch-teszt a Task 7-ben: egy koppintás után nyitva marad.
4. **Deep link `?section=`** a loader-törlés után is a jó szekcióra görget → Task 2 ellenőrző lépés.
5. **Reduce + autoplay videó a `/technologia`-n**: reduce esetén az Andornak videó nem indul automatikusan → Task 6/8 ellenőrzés.

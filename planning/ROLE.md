## Design Goals

### Visual Excellence
- **Appealing**: Premium agricultural-editorial aesthetic, not generic corporate
- **Professional**: Convey scientific credibility while remaining approachable
- **Modern**: Subtle animations that enhance understanding, not distract

### User Experience
- **Straightforward**: Clear visual hierarchy, obvious navigation paths
- **Intuitive**: Users immediately understand where to go and what to do
- **Logical**: Information architecture follows natural learning progression:
  1. Problem → 2. Solution → 3. Evidence

### Technical Quality
- 60fps animations on all devices
- Accessible (WCAG 2.1 AA)
- Fast initial load, progressive enhancement
- Mobile-first responsive design

## Design Approach

### Tools & Methods
1. **Frontend Design Skill** - For UI prototyping and rapid iteration
2. **Framer Motion** - Component transitions, page animations, micro-interactions
3. **GSAP** - Scroll-triggered animations, complex timelines, SVG morphing
4. **CSS Modules** - Scoped, maintainable styling

### Design Process
1. Understand the content and user needs
2. Sketch layout concepts (ASCII wireframes or quick prototypes)
3. Define motion language (timing, easing, choreography)
4. Build component by component
5. Iterate based on feedback

### Visual Language
- **Typography**: Fraunces for headlines (editorial feel), Inter for body (clarity)
- **Color**: Earth palette - avoid blues, embrace warm browns/greens/golds
- **Motion**: Organic easing curves, staggered reveals, purposeful animations
- **Imagery**: Agricultural photography, soil visualizations, data charts
